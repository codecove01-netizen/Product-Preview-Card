## 💡 What I Learned

While building this project, I strengthened my understanding of:

- Using the `<picture>` element to serve responsive images for different screen sizes.
- Creating responsive layouts with Flexbox.
- Applying a mobile-first workflow and enhancing the design with media queries.
- Organizing CSS using custom properties (CSS variables) for colors, typography, and spacing.
- Writing cleaner and more maintainable CSS with logical properties such as `margin-block` and `padding-inline`.
- Improving accessibility by implementing visible focus states for interactive elements.
- Structuring semantic HTML to create a more meaningful and accessible document.
